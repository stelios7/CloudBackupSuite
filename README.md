# Cloud Backup Core

## Overview
Cloud Backup Core is a WPF application designed to manage and save FTP settings efficiently. It allows users to configure settings dynamically, store them securely, and modify configurations with ease.

## Features
- **Settings Management**
  - Load and save FTP settings seamlessly.
  - Dynamic addition/removal of UploadSettings controls.
  
- **Enhanced Security**
  - Password storage optimized via PasswordBox behavior.
  - Settings files saved in a hidden, read-only directory.
  
- **User Interaction**
  - Confirmation message on window close to prevent accidental exits.
